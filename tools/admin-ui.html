本机

新闻

一篇新闻是一个片段文件，正文直接写 HTML（站点其余部分也是这样）。改动先落在这台机器的工作区， 在底部确认后再提交推送。

编辑

正文格式
空行分段；以 ##  开头是二级标题；**加粗**、`代码`、[文字](链接)。

公告

公告出现在每一页的最顶端。红色用于需要立刻知道的，黄色是提示。滚动用于长句子，静止用于短句。 置顶会让它随页面滚动常驻——同时只能有一条置顶。填了日期区间就会自动上线下线。

发布

确认后：跑一遍生成器 → 提交 → 用这台机器上的 git 凭据推送。CI 随之让线上生效。 能推送到这个仓库的人才能发布——这由 GitHub 的协作者设置决定，不在这里。

让别人也能发：在 GitHub 仓库的 Settings → Collaborators 里把对方加成协作者。 然后他 clone 仓库，跑 node tools/admin.mjs 就行——工具在仓库里，不需要另外发给他。
不需要发压缩包：这个工具本身不含任何凭据，能发稿的唯一条件是仓库写权限。 有写权限的人没有工具也能发（直接改文件 push 就行）；没有写权限的人拿到工具也发不了。
所以「只有我们几个能发」这句话，落到实处就是「协作者名单里只有我们几个」。
