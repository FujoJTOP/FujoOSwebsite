.fui：把界面变成文档

.fui / .fus 文档由 tools/fuic.py 编译成 .fuc，再由内核里的运行时渲染。桌面——壁纸、图标、面板、窗口——就是这样一份文档。它的好处和 L0 单源一脉相承：界面布局是数据，不是散落在代码里的常量。

.fuc 的节点是 64 字节的定长记录。这个布局此前同时存在于打包器、内核常量与文档三处，是 L0 收拢的第一批目标之一——见 L0 单一真源。
