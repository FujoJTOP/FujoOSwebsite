架构总览

这一节的全部内容，都是两条决策原则的推论：应用程序为中心；兼容性是内核的一等能力，而不是事后补丁。如果只记一句话，记这两条就够。

结构

分层与内核形态

四层是什么，以及为什么选混合内核：Ring0 只留 CPU 与空间管理。

 核心

系统调用闸门

三套 ABI 共享同一个内核服务面，差别只在编号映射。这是整个设计里最关键的一处。

 空间

内存与地址空间

页、大页、伙伴系统、按需零页，以及每个任务自己的页表链。

 执行

进程与隔离

统一底座、打包即权限、信号归一。

 持久

存储与 FJFS

内核只管块设备，文件语义全在用户态服务；FJFS 与真盘 AHCI。

 呈现

图形与窗口系统

帧缓冲、软件光栅、着色器 VM、wmsg 窗口系统，以及 .fui 声明式界面。

 连接

网络栈

virtio-net 三个原语、帧级用户 ABI，以及协议头为什么是 L0 要收掉的重复。

 边界

安全模型

内核不信任任何线程指针；能力句柄默认最小权限；垫片全 clean-room。
和 AI 层的关系： 内核这一节讲的是 S1 机制落地的位置——能力表、审计环、系统调用闸门都是同一套东西。算法与命题在 AI 层。
