C01–C15 规划

兼容线按 C01 → C15 推进，每一项都带一条可执行的判据——不是“完成 PE 装载器”，而是“非首选基址 + SEH 展开样例 PASS”。判据必须能被别人跑出来，否则它只是愿望。

前五项

编号 主题 判据（可执行）
C01 Linux ABI 第一公民加固 动态链接 + LTP 子集 + /proc 面 → LTP 子集 N 例与真实动态 ELF PASS
C02 PE 装载器深度 SEH / TLS 回调 / 延迟导入 / 重定位完整性 → 非首选基址与 SEH 展开样例 PASS
C03 kernel32 / ntdll 第二档 SHIM_TABLE +30，且每个 API 都带用例
C04 真实 CRT（msvcrt） 完整 printf / scanf 集与动态 CRT → mingw-w64 全链接程序 PASS
C05 LoadLibraryA 真实映射 导出表 / 转发导出 / 依赖递归 → 真 DLL 加载且 GetProcAddress 命中

C06–C15 覆盖 shim 面继续扩容、真实世界程序矩阵、跨架构翻译与签名 / 完整性容器等，与上面的硬缺口清单一一对应。

“不做”也写在规划里

一份只列待办的规划会让人误以为范围无边界。这份规划明确划掉了三样：内核驱动（.sys / .ko / .kext，改用 hypervisor 兜底）、完整 macOS GUI 等价、任何形式的专有代码复用。
