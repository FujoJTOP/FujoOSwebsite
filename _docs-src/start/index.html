开始

这一节的目标是：让任何一台装好工具链的机器，在不读源码的前提下，把 FujoOS 构建出来、跑起来，并且自己判断它是否真的工作。每一步都对应仓库里的一条命令，不是示意。

四步路径

第一步

环境要求

Rust nightly、Python 3、QEMU，以及哪些是可选的加速路径。

 第二步

构建内核

no_std crate 构建，以及为什么还需要把 ELF 压平成可被 -kernel 吃下的镜像。

 第三步

启动与运行

三种启动方式、monitor 里怎么选 demo、以及失败时先看哪里。

 第四步

回归、ISO 与 CI

59/59 是什么、ISO 自验证给出什么样的证据、静态门禁查什么。
读完这一节能得到什么： 一个能在自己机器上复现的“它确实启动了”的结论，以及知道每个数字是从哪条命令跑出来的。剩下三节（架构、AI 层、语言）讲的是它为什么这样设计。
