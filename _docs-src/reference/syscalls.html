系统调用

三套 ABI 共享同一个内核服务面，差别只在编号映射（见 系统调用闸门）。这一页是编号面的速查。

原生编号区段

区段 归属 说明
0x7D00–0x7D04模型卡mc_register / mc_call / mc_info / mc_audit
0x8100–0x83FFFUAI 契约面core 层与 host-ext 层的原语（46 个的归属见下页）
0x8316–0x8320盒桥（host-ext）Windows 宿主对象上的操作；不参与核心契约差分
0x8A04–0x8A06网络帧级 tx/rx，单帧 ≤ 1514 B
186 / 204 / 253网络驱动原语fujo_net_info / fujo_net_tx / fujo_net_rx

Linux 面：45 条 dispatch 臂

一等公民，原生执行、零垫片。命名表已同步为实现面 45 条——此前有 15 条臂没有名字，是 C12 度量抓出来的，处理方式见 Linux ABI 一节。

按功能归类（条目名即 dispatch 臂名）
类别 条目
进程与身份 getpid · gettid · getuid · getgid · geteuid · getegid · set_tid_address · set_robust_list · get_robust_list · prlimit64 · rseq · unlink
时间与同步 time · clock_gettime · futex
文件与内存 （其余实现面条目，含 mmap / brk 一类）
尚未实现（C01 / C08 目标） poll · ioctl · pread64 · readv · select · sched_yield · socket · connect · accept · wait4
最后一行值得单独看： 这 10 条是“名字占着但没有实现”的。其中 socket 族是 网络线 的前置条件——所以在规划里它的优先级比它在表中出现的位置要高。
一致性来源： 本页条目与实现面的对齐由 tools/compat_audit.py 的“表↔臂一致性”检查维持，不一致会直接报出来。
