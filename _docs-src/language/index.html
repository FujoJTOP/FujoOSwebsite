语言总览

先说清楚一件容易误会的事：Loment 和 Potato 不是两门语言在竞争。Loment 是语言（语法、类型、所有权、能力域），Potato 不是语言——它是编译流程输出端的形式对象，没有语法，只有结构。一个管怎么写，一个管怎么看。

这层关系不是凭空设计的，它来自一个很具体的痛点：同一个事实在 JSON、Rust、C、Python 里各写一份。立项文档列了十个这样的痛点，其中七个是重复声明。关键推论是——这十个痛点里没有一个是 Rust 造成的，换语言不解决它们，只会增加语言数量。

现在就能做

L0 单一真源

一份 .lom 声明，生成 Rust / C / Python / JSON，漂移在生成期就不可能发生。

 语言本体

Loment 语言

Rust 的严格子集，加少量显式扩展——语法不新，语义才新。

 接缝

能力域即语言构造

能力不是库调用，是语言里的东西：guard、编译期边界、运行期 trap、审计计数。

 机器面

Potato 形式对象

编译器强制导出，不可关闭；内核、验证器、外部 Agent 读同一份。

 周边

工具链

格式化器、LSP、包管理器、文档生成器、DWARF 行表、增量构建。

 闭环

自举

编译器编译自身，三阶段产物逐字节相同——以及它明确写下的未竟项。

 证据

波 C 测量

把“能转写”变成可复现的数字：识别率、转换率、置信区间。以及必须一起读的原因。

 应用

第一个真应用

为什么让一门新语言的第一个真应用是网络，而不是玩具样例。
