怎么用这套文档

如果你想… 从这里开始
把它跑起来，自己看是不是真的 开始 → 回归、ISO 与 CI
理解“AI 在内核里被约束”是什么意思 命题与 S1/S2/S3 → A1–A4 → 运行时与证据链
看这套机制能不能搬到别的宿主上 运行时与证据链 → 盒桥
搞清楚 Loment 和 Potato 到底谁管什么 语言总览 → Potato 形式对象
检查“兼容”这个词被用在了什么范围 兼容总览 → 已知边界
找某个系统调用或操作码 系统调用 · FUAI 操作码
知道这个项目明确不做什么 路线图 · 已知边界
文档纪律： 仓库里的数字与判据不靠文档自证，而靠 tools/ 下的脚本重跑。文档写的是结论与边界，脚本才是证据——所以这里的每一句话都应该能被一条命令推翻。
