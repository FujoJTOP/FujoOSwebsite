明确推迟与明确不做的事

一份只写“要做什么”的路线图是不完整的。下面这些是主动划出去的，理由一并写上。

  • 微核自引导 —— 推迟到 FUAI-OS 发布之后，作为“第三后端”探索，不前置。
  • 常驻评测设施 —— 永不建，用一键复现包替代。理由见 可复现性纪律。
  • 内核驱动的兼容层 —— .sys / .ko / .kext 不做，提供 hypervisor 兜底。
  • 完整 macOS GUI 等价 —— 不做；兼容目标限定在加载器与垫片面。
  • 物理介质执行 —— 可选后续项，不再阻断真机闭环的关闭。
  • 公开投稿 —— 论文按浙大要求保持私有；预印本时间戳是优先权的唯一锚点。
