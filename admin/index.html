连接

需要一个只对这个仓库有写入权限的 GitHub 细粒度令牌（Fine-grained token），权限只需 Contents: Read and write。不要用 classic token——那等于整个账号的写权限。 令牌不加密，只存在这台设备的浏览器里，也只会发往 api.github.com。 任何拿到它的人都能写这个仓库。

新闻

一篇新闻是一个片段文件，正文直接写 HTML（站点其余部分也是这样）。保存后进入待发布清单， 在页面底部统一提交。

编辑

公告

公告出现在每一页的最顶端。红色用于需要立刻知道的，黄色是提示。滚动用于长句子，静止用于短句。 置顶会让它随页面滚动常驻——同时只能有一条置顶。填了日期区间就会自动上线下线。
